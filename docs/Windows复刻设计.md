# 妙言 Windows 完整复刻设计

状态：设计草案，尚未实现。技术选型和完整复刻范围已由用户确定。

## 基线与交付

- Tauri 2 + React + TypeScript + Vite；Rust 负责文件和系统能力。
- 原版参考： https://github.com/tw93/MiaoYan ，固定提交 `668e367e4937bd5c887562991400636ced1d3e58`。后续上游变动不自动扩大本次范围。
- 默认 Windows 10/11 x64；交付源码、锁文件、可安装 EXE、功能验收记录。ARM64 不作为本轮默认验收平台。
- 完整复刻指桌面产品功能和交互覆盖，包括高级功能；分阶段实现不代表裁剪最终范围。不移植 iOS 客户端。
- 保留三栏结构、排版、配色、模式切换和操作习惯；窗口按钮、系统菜单和快捷键适应 Windows。
- 暂用「妙言 Windows（非官方）」作为工作名称，保留原项目版权与 MIT 许可；第三方库、字体和图标逐项核对许可，不能直接假定全部属于 MIT。

## 实现结构与复用

React 负责工作区、列表、CodeMirror 6 编辑器、偏好和历史面板。CodeMirror 用于编辑、选区和撤销，不自研编辑器。Markdown 解析采用 markdown-it 及必要扩展，通过对照样本验证与原版 cmark 的差异。

预览优先复用原版 DownView 中可移植的样式、渲染逻辑和 Reveal.js 资源；替换 WKWebView 专用消息桥接。预览与可调用 Tauri 命令的应用界面隔离，预览内容不得直接获得文件写入或进程权限。TOC 跳转、任务勾选等只接受白名单消息，并核对当前文档和渲染代次。

Rust 命令按文件管理、读写、历史、导出和系统集成组织。文件访问限定在用户选定工作区、明确打开的文件及应用数据目录，校验规范化路径、符号链接和 Windows junction，拒绝路径逃逸。系统调用使用结构化参数，不拼接 shell 命令。

Markdown 文件是数据源，不引入笔记数据库。延续相邻 `i/` 图片和 `files/` 附件约定；偏好、索引缓存、历史和诊断存入应用数据目录。索引可从文件重建。原版历史数据库不视为天然兼容，但原版笔记及相对附件要可直接打开。

## 保存与冲突处理

编辑缓冲区始终绑定明确文档身份和版本，异步保存携带该身份。对同一文档串行写入，采用同目录临时文件与 Windows 可用的安全替换方式；实现时验证已有目标文件替换语义，不假定所有平台 rename 行为相同。

保存前检测磁盘版本。外部编辑与本地未保存内容冲突时保留双方版本；外部删除后禁止后台自动重建旧文件。切换、移动、改名、退出前等待相关保存完成；失败保留缓冲区，提供重试或另存。文件监听事件按文档版本去重，避免自写回环。

历史按变更建立快照，编辑期间与原版约五分钟节奏对齐，并在恢复/冲突等关键操作前留存。测试必须覆盖 A/B 笔记快速切换、删除时保存仍在排队、写盘失败和外部更新。

## 平台对应与外部依赖

- Finder → 资源管理器；Command 主快捷键 → Ctrl，并检查 Windows 冲突。
- iCloud 专属协调 → 本地文件监听与冲突保护。同步交给用户已安装的 OneDrive、坚果云或其他同步客户端；不另造云同步服务。
- 图床接入优先使用 Windows 可用的 PicGo 等服务。macOS 专用上传工具无法原样运行，替换为同等上传入口和本地回退。
- PlantUML 保留服务渲染方式，可配置服务地址，首次发送图表内容前由用户选择启用。其他可本地渲染的公式和图表随包提供。
- PDF 优先验证 WebView2 原生打印到 PDF；长图需要分段渲染/拼接以避开纹理尺寸限制。这两项列为早期技术验证，不以弹出打印对话框冒充一键导出完成。
- 在线更新和应用代码签名分开：更新功能需要应用专属密钥与发布源；Windows 代码签名证书未提供时如实交付未签名安装包，不宣称已签名。

## 实施顺序

1. 检查 Rust/MSVC/WebView2 环境；验证安全文件替换、预览隔离、PDF/长图导出可行性。
2. 建立真实文件工作区、三栏界面、编辑、保存、监听、冲突保护、回收站。
3. 完成全部 Markdown/图表、分栏同步、TOC、链接、附件、排版和偏好。
4. 完成历史、全部导出、PPT、CLI、系统集成和更新流程。
5. 逐项跑矩阵回归，在真实 Tauri 窗口验证中文输入法、DPI、键盘、安装升级卸载，交付安装包与真实验收结果。

不以网页预览通过替代桌面验收；只有矩阵全部完成，或明确记录用户接受的平台替代项，才称完整复刻完成。
